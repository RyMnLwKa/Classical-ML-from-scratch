# Machine Learning From Scratch

Учебная коллекция ноутбуков с реализациями ML-алгоритмов с нуля (NumPy/pandas), с теоретическими выкладками, тестами и сравнением со sklearn.

## Структура репозитория

| Файл | Краткое содержание |
|---|---|
| `DiscrAnalysis.ipynb` | Дискриминантный анализ: вероятностный LDA, LDA через критерий Фишера (отношение Рэлея), LDA через МНК, LDA через SVD, KLDA (kernel trick), вероятностный QDA. Сравнение всех реализаций со sklearn на сгенерированных датасетах. |
| `LinearRegr.ipynb` | Итеративная линейная регрессия: GD-реализация, знакомство с `nnls` (NNLS vs положительный OLS из sklearn), демонстрация линейности по параметрам через преобразование признаков (логарифмирование). |
| `LogReg.ipynb` | Логистическая регрессия через градиентный спуск: сигмоида, градиенты, проверка сходимости по изменению градиента, тест на `make_classification`. |
| `Metric(nonparam)_methods.ipynb` | Метрические методы: KNN из sklearn, своя реализация KNN с множеством опций (ядра Парзена фикс./перемен., линейные/экспоненциальные веса, пакетный режим, landmarks-аппроксимация по плотности/энтропии/рандому), LOO-кросс-валидация для подбора гиперпараметров, сравнение способов вычисления расстояний (матричный, векторно-итерационный, пакетный), свой KDTree и proximity graph (NSW). |
| `NaiveBayes+Gama-process modeling.ipynb` | Наивный байес (параметрический гауссовский и непараметрический с ядрами) + моделирование гамма-процесса: интерполяция непрерывного признака, интегрирование интенсивности A(t) в нестационарном пуассоновском потоке, MLE для параметров гаммы (фактически координатный спуск с ММ/градиентный спуск с счетом в конце через ММ), L-BGFS и Adam для оптимизации. |
| `Optimization.ipynb` | Оптимизаторы: MomentumGD (+ дополнительные "физические" силы: центростремительная, упругая, маржинальная, термостат), AdaGrad, AdaGradNorm, RMSProp, Adam. Сравнение всех на линейном и нелинейном датасетах, выводы о свойствах каждого. |
| `RandomForest.ipynb` | Деревья: CART, C4.5 (с gain ratio, числовыми признаками, ccp-прунингом), обёртки с RSM (random subspace method), Random Forest (свой, с OOB-оценкой, синхронный/async/parallel через joblib), заготовки под ITree и Isolation Forest. |
| `SVC(SVR).ipynb` | SVM: soft-margin SVC через GD, мини-батчи и SGD, **авторский SMO на основе лагранжиана (с проекцией на прямоугольник и прямую)**, SMO из Хабра (30 строк). Визуализация границы решения и отступов, диагностика сходимости и опорных векторов. |
| `Autoencoder.ipynb` | Автоэнкодер (TensorFlow): собственная реализация `Dense`-слоёв, настраиваемая функция потерь с регуляризаторами (Lasso, Ridge, ортогональность, KL-дивергенция для разреженности, монотонность дисперсии), сравнение с PCA по ошибке восстановления (MAE), визуализация и анализ латентного пространства, оценка ортогональности через VIF и углов между базисами (subspace angles), доказательство эквивалентности линейного AE и PCA через инициализацию весов компонентами PCA. |
